# M1 — Parser core

Cut from `spec/SPEC.md` §5, §18, §19 plus `research/sch-format.md` (R1) and
`research/sexpr-strategy.md` (R2). Decisions from `DECISIONS-R6.md`.

**Goal of M1.** A token-preserving syntax tree and an exact re-emitter for
`.kicad_sch`, `.kicad_sym` and `.kicad_pro`, with the P1 and P2 round-trip
properties gating merges, the in-repo fixture corpus bootstrapped, and
`cargo xtask corpus` fetching KiCad's GPL demo/`qa` files into `target/` for the
external gates.

**Rules for this milestone.**

- Constitution §11: every task below names an executable completion check. A
  task is not done until that exact command passes.
- Tasks are ordered; each depends only on those above it. Where two are
  independent that is noted.
- No command surface, no geometry, no lint. M1 ends at "parse and re-emit
  faithfully", exposing the API M2 consumes.
- `cargo test` (no features) must stay hermetic: no network, no `kicad-cli`, no
  GPL files. External-corpus and oracle tests are feature- or env-gated.

## BLOCKED — needs a decision before the dependent task starts

**B1 — `.kicad_pro` writer fidelity is not covered by any research doc.**

`.kicad_pro` is JSON, not s-expression, so none of R1/R2 applies to it. Unknown:
KiCad 10.0.5's indent width, key ordering, float formatting, unicode escaping,
and trailing-newline behaviour when it rewrites a project file. M1 needs
`.kicad_pro` because v10 moved **bus aliases** there (`sch-format.md` §5.6) and
because ERC severities live there (`spec/SPEC.md` §14.3).

The question is the same shape as Q3 for s-expressions, but the answer cannot be
inherited: **if a KiCad-written `.kicad_pro` cannot be reproduced byte-for-byte
by an order-preserving JSON writer, does kicli (a) reformat and set
`"reformatted": true`, or (b) refuse to write `.kicad_pro` at all in v1?**

Recommendation: run T18 (a pure measurement, no policy) first, then pick. If the
gap is only whitespace, (a) mirrors Q3 and costs nothing. If KiCad reorders keys
or reformats numbers, (b) is safer — v1 has no command that *needs* to write
`.kicad_pro` (bus aliases are read-only for M1–M8; ERC severities are
relabel-only per Q32), so refusing to write costs nothing either.

**T19 is blocked on this answer. T18 is not** — it is the experiment that
informs it and should be run regardless.

Nothing else in M1 is undecidable from `DECISIONS-R6.md`.

## Tasks

### T1 — Workspace skeleton and licence gate

Create the cargo workspace (`kicli` binary crate + `kicli-sexpr` library crate +
`xtask`), dual `LICENSE-MIT` / `LICENSE-APACHE`, `.gitignore` covering
`target/`, `.kicli/`. Add `deny.toml` allowing MIT/Apache-2.0/BSD only —
**MPL-2.0 must be denied** (Constitution §9, Q8).

- **Check:** `cargo build --workspace && cargo deny check licenses` exits 0, and
  `cargo deny check licenses` fails when an MPL-2.0 crate is temporarily added.

### T2 — In-repo fixture corpus, bootstrapped

Author `fixtures/sch/` by hand (small, purpose-built, our content — D18) and
canonicalise each once with `kicad-cli sch upgrade --force`, which is verified
idempotent. Minimum set, chosen to exercise the traps in R1:

| Fixture | Exercises |
|---|---|
| `minimal.kicad_sch` | smallest valid v10 file |
| `all_items.kicad_sch` | one of every top-level token in `sch-format.md` §1 |
| `escapes.kicad_sch` | `text_box` with embedded `\"` and `\n` (§2.2) |
| `polyline_xy.kicad_sch` | long `(xy …)` runs, to hit the column-99 packer |
| `multi_instance/` | one sheet placed twice, symbol with two `instances` paths and two references (§3.4, §3.6) |
| `lib_name_redirect.kicad_sch` | `(lib_name "GND_1")` differing from `lib_id` |
| `compact_save.kicad_sch` | written with `CompactSave` = true |
| `v9_legacy.kicad_sch` | `(version 20250114)`: `~`-as-empty, `hide` inside `effects` |
| `commented.kicad_sch` | `#` line comments |
| `noncanonical.kicad_sch` | hand-indented, two-space, no inter-list spaces |
| `future_version.kicad_sch` | stamp `20260803` (above the ceiling) |
| `embedded_font.kicad_sch` | non-trivial `embedded_files` base64 blob |
| `device.kicad_sym` | symbol library, `(version 20251024)` |
| `sym-lib-table`, `fp-lib-table` | `LIBRARY_TABLE` mode, one canonical + one legacy |

Check each canonicalised fixture for bus aliases before committing — `upgrade`
destroys them (`sch-format.md` §5.6). Add `fixtures/MANIFEST.toml` recording, per
fixture, its version stamp, expected prettifier mode, and canonicality.

- **Check:** `cargo test fixtures_manifest_complete` — asserts every file under
  `fixtures/` appears in `MANIFEST.toml` and vice versa, and that every fixture
  declared canonical ends in exactly one `\n`.

### T3 — Byte lexer

Five token classes over `&[u8]`, UTF-8 validated once up front: `LParen`,
`RParen`, `QuotedString` (`'"' ( '\\' . | [^"\\] )* '"'`), `BareAtom`
(`[^ \t\r\n()"]+`), `Comment` (`#` as first non-blank on a line, mirroring
`dsnlexer.cpp:575`). **No number classification and no escape processing at lex
time** — both are queries on the node, so `41.91` can never come back as
`41.910000000000004` (`sexpr-strategy.md` §4.1).

- **Check:** `cargo test lexer` — unit tests per class plus a table test
  asserting that re-concatenating every token's source span reproduces the input
  minus inter-token whitespace, for every fixture in T2.

### T4 — Arena tree and `Doc`

`Doc { src, nodes: Vec<Node>, root, mode, canonical }` with
`Node::{ List { head, children, span }, Atom { kind, span, edited }, Comment }`,
index-based `NodeId` handles. The span into the original source is the source of
truth for unedited atoms; `edited: Option<Box<str>>` is `None` until kicli
changes a value. This makes "never rewrite a token we did not modify" structural
rather than a convention (`sexpr-strategy.md` §4.2). Memoise the head atom so
`list.head_is("symbol")` is O(1).

- **Check:** `cargo test tree_spans` — for every fixture, walk the tree and
  assert every atom's `&src[span]` is byte-equal to what the lexer produced, and
  that node count matches the token count.

### T5 — `flatten`

Delete every whitespace run outside quotes, replacing it with a single space.
Destroys layout, preserves tokens. This is the input to the prettifier identity
test.

- **Check:** `cargo test flatten_preserves_tokens` — `lex(flatten(f))` yields the
  same token list as `lex(f)` for every fixture, with quote-aware handling
  verified by `escapes.kicad_sch`.

### T6 — `Prettify` port, NORMAL mode

Literal port of `KICAD_FORMAT::Prettify` (`common/io/kicad/kicad_io_utils.cpp:97-339`),
including the four rules the doc comment omits: `(xy …)` run-packing to
`xySpecialCaseColumnLimit = 99`; the `consecutiveTokenWrapThreshold = 72` long-token
wrap; backslash-parity quote tracking so `\\"` is not read as an escaped quote;
exactly one trailing `\n` (`sch-format.md` §2.1).

- **Check:** `cargo test prettify_fixtures` — `prettify(flatten(f)) == f` for
  every fixture in T2 declared canonical+NORMAL, and
  `prettify(prettify(x)) == prettify(x)` (idempotence) for all of them.

### T7 — `cargo xtask corpus`

Fetch KiCad at pinned tag `10.0.5` into `target/corpus/` (shallow clone), copy
`demos/` and `qa/data/`, and canonicalise the demo schematics with
`kicad-cli sch upgrade --force` (recipe C, `sch-format.md` §0.2). **GPL files
never enter the repo** (Q5, C21) — `target/` is gitignored. Skip with a clear
message when `kicad-cli` or network is absent.

- **Check:** `cargo xtask corpus && cargo xtask corpus --verify` — the second
  invocation asserts 115 `.kicad_sch` at `(version 20260306)`, ≥ 36 library
  tables, and that `git status --porcelain` is empty afterwards.

### T8 — Prettifier identity over the external corpus (permanent gate)

The 115/115 result in `sexpr-strategy.md` §2.2 becomes a test. Feature-gated so
the default `cargo test` stays hermetic.

- **Check:** `cargo test --features corpus prettify_corpus_identity` — 115/115
  `.kicad_sch`, 6/6 sampled `.kicad_pcb`, and the shipped `Device.kicad_sym`
  satisfy `prettify(flatten(x)) == x`. The test prints the pass count and fails
  if it is below 115.

### T9 — Prettifier modes and detection

Add `COMPACT_TEXT_PROPERTIES` (keeps `font stroke fill teardrop offset rotate
scale` on one line) and `LIBRARY_TABLE` (one `lib` row per line). Detect the
input's mode as the one in which it is a fixed point, and **preserve it on
write** — editing one field in a `CompactSave` user's file must not reformat the
whole file (Q4, `sexpr-strategy.md` §2.4).

- **Check:** `cargo test prettify_modes` — `compact_save.kicad_sch` detects
  `CompactTextProperties` and round-trips byte-identically; the canonical
  `sym-lib-table` detects `LibraryTable` and round-trips; the legacy one detects
  non-canonical.

### T10 — Fixed-point integer formatter, with the `{:.10g}` equivalence proof

`fmt_iu(v: i32) -> String`: format the integer IU as fixed-point mm with 4
fractional digits, strip trailing zeros then a trailing `.`. This avoids float
formatting entirely and is claimed identical to KiCad's `{:.10g}` output for all
`int32` inputs (`sch-format.md` §2.3). The claim must be **proved, not
asserted.** Also `fmt_angle` for `{:.10g}` on degrees, and the separate paths for
`(color …)` alpha and `(scale …)` (`{:g}`).

- **Check:** `cargo test --release fmt_iu_equivalence` — a reference
  implementation of `{:.10g}` (or a committed table generated from C++ `fmt`)
  compared against `fmt_iu` across the **full `i32` range** in release mode,
  plus the `|value| <= 0.0001` branch. Test fails on the first divergence and
  prints it.
- **Check:** `cargo test --features corpus fmt_iu_corpus` — every numeric atom in
  the external corpus parses to an `i32` IU and re-formats to its exact original
  bytes.

### T11 — String quoting and unquoting

Escape exactly four characters — `\n`, `\r`, `\\`, `\"` — and nothing else. No
`\t`, no `\uXXXX`, no octal; UTF-8, tabs, and parens inside strings are written
raw (`richio.cpp:468`, `sch-format.md` §2.2). User data is always quoted; keyword
tokens are always bare.

- **Check:** `cargo test quoting` — round-trip property over nasty strings
  (embedded quotes, backslashes, newlines, UTF-8, empty, `~`, `#`-leading, a
  literal tab), plus a byte assertion against the `text_box` line in
  `escapes.kicad_sch`.

### T12 — Emitter

Two stages mirroring KiCad: walk the tree to a flat token stream with single
spaces, then prettify in the detected mode. Emission prefers `edited`, else
`&src[span]`.

- **Check:** `cargo test emit_unedited_is_identity` — for every canonical
  fixture, `emit(parse(f)) == f` bytewise with no edits applied.

### T13 — P1 gate: byte-identical round trip for KiCad-authored input

Promote T12's property to a named merge gate over both corpora
(`spec/SPEC.md` §5.3).

- **Check:** `cargo test roundtrip_p1` (fixtures) and
  `cargo test --features corpus roundtrip_p1_corpus` — both must be 100 % over
  files the manifest/corpus marks canonical. Non-canonical files are excluded
  here and covered by T14.

### T14 — P2 gate: semantic round trip for every input

`parse(emit(parse(f))) ≡ parse(f)` — structural equality of the tree modulo
whitespace and atom spans. This is the property that must hold for *all* input,
including non-canonical and pre-v10 files, and is the honest floor Constitution
§1 describes.

- **Check:** `cargo test roundtrip_p2` and
  `cargo test --features corpus roundtrip_p2_corpus` — 100 % including
  `noncanonical.kicad_sch`, `v9_legacy.kicad_sch`, and every `qa/data` file
  (which are deliberately pathological and include older format versions).

### T15 — P3 harness: mutation locality

Provide `Doc::set_atom(NodeId, &str)` plus a `line_diff` helper, and assert an
edit touches only its own region. The commands come in M3; the harness and the
property are M1's, because it is the property most likely to regress silently
(`sexpr-strategy.md` §5 L3).

- **Check:** `cargo test roundtrip_p3` — editing one `property` value atom in
  `all_items.kicad_sch` changes ≤ 3 lines of output; editing one `(xy …)`
  coordinate changes ≤ 1 line; the rest of the file is byte-identical.

### T16 — Write policy: canonicality, comments, version ceiling

Implement the §5.4 table: non-canonical input is reformatted with
`"reformatted": true` and a reason; `#` comments cause a **refusal to write**
unless `--allow-comment-loss`; a version stamp above `formats.max_schematic_version`
(default `20260306`) causes a refusal. Refusals are exit 4 with structured
errors (`spec/SPEC.md` §6.1).

- **Check:** `cargo test write_policy` — four cases: `noncanonical` writes and
  reports `reformatted: true`; `commented` refuses by default and succeeds with
  the flag (and the comment is gone); `future_version` refuses and succeeds with
  the config override; a canonical file reports `reformatted: false`.

### T17 — Version-gated semantics

Key `~`-means-empty (below stamp `20250318`) and `hide` placement (inside
`effects` below `20251028`) off the file's `(version …)`, which is available
before any item is interpreted because it is the first child
(`sch-format.md` §5.1, §5.3). Preserve the two distinct `property` field
orderings: instance fields write `hide` first, `lib_symbols` fields write it last
(§3.4, §4).

- **Check:** `cargo test version_gating` — `v9_legacy.kicad_sch` round-trips
  under P1 with `~` preserved as a literal token and `hide` left inside
  `effects`; a v10 fixture keeps the v10 orderings; a test asserts the two
  property orderings are not swapped.

### T18 — `.kicad_pro` fidelity experiment (informs B1)

Measurement only, no policy. Read a KiCad-written `.kicad_pro` (from T2 and from
the external corpus) with an order-preserving JSON reader, write it back
unchanged, and report exactly how the bytes differ: key order, indent, float
formatting, unicode escaping, trailing newline.

- **Check:** `cargo xtask pro-fidelity` — prints a per-file diff summary and a
  verdict line (`byte-identical` / `whitespace-only` / `reorders-keys` /
  `reformats-numbers`) for every `.kicad_pro` in fixtures and corpus. Commit the
  output to `research/notes/kicad-pro-fidelity.md`.

### T19 — `.kicad_pro` read/write — **BLOCKED on B1**

Implement whichever of B1(a) or B1(b) James picks. Either way, `.kicad_pro`
**reading** is required now: bus aliases moved there in v10 and M2's
connectivity extraction needs them, and ERC severities are read for the
relabel-only mapping (Q32).

- **Check (unconditional part):** `cargo test kicad_pro_read` — bus aliases and
  `erc.rule_severities` are extracted from a fixture project file.
- **Check (policy part):** `cargo test kicad_pro_write_policy` — asserts the
  chosen behaviour, byte-identity under (a) where achievable, or a structured
  refusal under (b).

### T20 — `.kicad_sym` support

The symbol-body serialiser is shared between `.kicad_sym` and the schematic's
`lib_symbols` (`sch-format.md` §4), so one parser covers both. Handle the
`NAME_<unit>_<bodyStyle>` child naming and the per-symbol `(embedded_fonts no)`.

- **Check:** `cargo test kicad_sym_roundtrip` on `fixtures/device.kicad_sym`, and
  `cargo test --features corpus kicad_sym_shipped` on the installed
  `Device.kicad_sym` (skipped with a message when KiCad is not installed).

### T21 — Embedded files are opaque

`embedded_files` / `embedded_fonts` blobs are carried as untouched spans, never
re-encoded, and any operation that would move them between files is refused
(Q6). The **absence** of `embedded_fonts` is not corruption — v10 writes it only
for the top-level sheet (`sch-format.md` §5.5).

- **Check:** `cargo test embedded_opaque` — `embedded_font.kicad_sch` round-trips
  byte-identically after an unrelated edit elsewhere in the file; the base64
  span is asserted untouched; a cross-file move attempt returns a structured
  refusal.

### T22 — Generative property tests and fuzzing

A `proptest` strategy building random *valid* trees (random nesting, nasty
atoms) asserting `parse(emit(t)) ≡ t` and prettifier idempotence, plus a
`cargo-fuzz` target asserting **no panic** on arbitrary bytes — the parser will
be fed agent-generated files (`sexpr-strategy.md` §5 L4).

- **Check:** `cargo test proptest_roundtrip` (default 256 cases) and
  `cargo fuzz run parse -- -max_total_time=60` with zero crashes; the fuzz corpus
  seeds from `fixtures/`.

### T23 — L5 oracle: agreement with KiCad's own writer

When `kicad-cli` is available, run `sch upgrade --force` on a copy of kicli's
output and assert the result is unchanged — i.e. kicli's output is already what
KiCad would write. This tracks P4 (informational, never gating) and catches
drift from KiCad's evolving canonical form. `sch upgrade` is verified idempotent,
which is what makes it a valid oracle.

- **Check:** `KICLI_TEST_KICAD_CLI=1 cargo test --features corpus oracle_upgrade`
  — reports the pass rate; **does not fail the build**, per P4's informational
  status. Excluded from the default run.

### T24 — Ecosystem regression fixture

Encode the R6 result as a permanent test: on the same KiCad 10.0.5 sheet where
`kiutils` 1.4.8 loses 2,912 of 19,851 tokens (14.7 %) and `kicad-skip` 0.2.5
loses none but reformats, kicli must lose zero tokens **and** be byte-identical
(`ecosystem.md` §2, §7). Commit the token-count expectations, not the Python
tools.

- **Check:** `cargo test ecosystem_regression` — asserts kicli's token count in
  equals token count out on `fixtures/sch/ampli_ht_equivalent.kicad_sch`, and
  byte-identity; the committed comparison table (`fixtures/ecosystem.toml`)
  records the two Python results for the claim in `spec/SPEC.md` §4.

### T25 — Public API surface for M2, and docs

Freeze what M2 consumes: `Doc::parse`, `emit`, node navigation by head token,
UUID → `NodeId` index, `AtomKind` queries (`as_i32_iu`, `as_str`), `FormatMode`,
`canonical`, and the structured write-result type carrying `reformatted` and the
verification report shape Constitution §5 requires.

- **Check:** `cargo doc --no-deps` with `#![deny(missing_docs)]` on the library
  crate, and `cargo test --doc` — every public item documented with a doctest
  that parses a fixture and re-emits it.

## Milestone exit criteria

M1 is complete when all of the following pass on a clean checkout:

```sh
cargo build --workspace
cargo deny check licenses
cargo test                                   # hermetic: fixtures only
cargo xtask corpus
cargo test --features corpus                 # includes 115/115 prettifier identity
cargo fuzz run parse -- -max_total_time=60
```

and `cargo test --features corpus roundtrip_p1_corpus roundtrip_p2_corpus`
reports 100 % on canonical files (P1) and 100 % on all files (P2).

T19's policy half may remain open only if B1 is still unanswered; in that case
M1 ships with `.kicad_pro` **read-only**, which is sufficient for M2–M8, and the
open item carries forward into M9's task list.
