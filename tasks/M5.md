close to hold the items M4 measured and ruled forward, so they land in the
milestone that owns them rather than ageing in a closed one. The milestone's own
tasks are cut from `spec/SPEC.md` §11 and `research/style-rules.md` when M5 is
planned; nothing below is a task yet.

The reason it exists at all: a debt recorded in a closed milestone is a debt
nobody reads. M4's chore table made owners mandatory precisely because an
unowned debt is an unpaid one, and "carried into M5" is only an owner if there
is an M5 file to carry it into.
